========================================================================
 SW MultiSync — Stormworks 車両位置同期の改善ツール（専用サーバー用）
========================================================================

これは何？
  Stormworks の専用サーバー(server64.exe)に組み込んで、遠くにいる車両の
  位置がカクついたり大きく遅れて見える問題を改善するツールです。
  サーバー(ホスト)側だけに入れれば効きます。参加者(クライアント)側の
  インストールは不要です。

------------------------------------------------------------------------
 同梱ファイル（全部「同じフォルダ」に置いてください。場所はどこでもOK）
------------------------------------------------------------------------
  SWMultiSync.exe   … 操作画面。これを起動するだけ
  swhook.dll       … 本体（サーバーに組み込まれる部分）
  swhook.ini       … 設定ファイル（そのままでOK。画面から編集できます）
  swctl.exe        … コマンドライン版（自動化・上級者向け。通常は不要）
  README_はじめにお読みください.txt … このファイル

------------------------------------------------------------------------
 使い方
------------------------------------------------------------------------
  1) SWMultiSync.exe をダブルクリックで起動する。
     ・「このアプリがデバイスに変更を加えることを許可しますか」と出たら
       「はい」を押してください（サーバーに組み込むために必要です）。

  2) いつも通り Stormworks の専用サーバー(server64.exe)を起動する。
     ・順番はどちらが先でも構いません。ツールがサーバーの起動を検出して
       自動で組み込みます。

  3) 画面上部が「swhook: 動作中 (vX.X.X)」になり、
     「状態」タブの大きなボタンが「同期改善: ON」なら効いています。
     ・ボタンを押すと ON/OFF を切り替えられます。
     ・既定では組み込み時に自動で ON になります（「起動・注入」タブで変更可）。

  画面は閉じても効き続けます（サーバー内で動いているため）。
  サーバーを終了すると元に戻ります。次回もまた SWMultiSync.exe を起動して
  ください。

------------------------------------------------------------------------
 画面の見かた
------------------------------------------------------------------------
  状態タブ
    ・通信量: 「ゲーム本来」＝サーバーがもともと送っている量、
               「同期追加」＝このツールが上乗せしている量（毎秒）
    ・解析率: サーバーの通信をツールが理解できた割合。100%近くが正常。
    ・参加プレイヤー: SteamID ごとの通信量など
    ・車両: サーバー上の車両の位置・更新間隔と、誰がどの間隔で受け取っているか（デバッグ用。チェックで表示）
  設定タブ
    ・同期のきめ細かさや通信量上限を変えられます。稼働中すぐ効きます。
      「iniに保存」で次回以降にも残ります。
      capKbpsPerPeer … 参加者1人あたりの追加通信量の上限 (kbit/s)。
                       回線が細いときに下げてください。
  起動・注入タブ
    ・自動組み込み、組み込み時の同期 ON/OFF、録画の有無、制御ポート。
  ログ・録画タブ
    ・不具合調査用。「録画開始」で通信内容を .swcap ファイルに保存します。

------------------------------------------------------------------------
 ゲーム内から稼働状態を確認する（?multisync）
------------------------------------------------------------------------
  サーバーに参加している人なら誰でも、ゲーム内チャットで

      ?multisync

  と送ると、送った人にだけ次のような返事がチャットに出ます。

      [SW_MultiSync] SW_MultiSync v0.2.2  relay: ON

  ・返事が出れば swhook が組み込まれて動いています（v… はそのバージョン）。
  ・relay: ON なら同期改善が有効、OFF なら無効です。
  ・何も出なければ組み込まれていません（またはサーバーが古い版です）。
  ・先頭が ? なのでチャット欄には表示されず、他の人には見えません。
    大文字小文字や空白も含めて完全に一致したときだけ反応します。

------------------------------------------------------------------------
 注意点
------------------------------------------------------------------------
  ・64bit の Windows / server64.exe 専用です。
  ・ウイルス対策ソフトや SmartScreen が警告を出すことがあります
    （プログラムを別プロセスに組み込む仕組みのためです）。
    知人から受け取ったこのツールを信頼する場合のみ「許可」して
    ください。心配な場合は実行しないでください。
  ・ツールは 127.0.0.1（このPC内だけ）の TCP ポート 28215 を使います。
    他のソフトとぶつかる場合は「起動・注入」タブで変更してください。

------------------------------------------------------------------------
 効果を体感するには
------------------------------------------------------------------------
  1人が車両で数km〜10kmほど離れた場所を動き、もう1人がそれを
  遠くから観測すると、同期改善 ON/OFF で見え方が変わります。
  （OFF だと遠くの車両は大きく遅れてカクつきます）

------------------------------------------------------------------------
 うまくいかないとき / 不具合の連絡
------------------------------------------------------------------------
  「swhook: 未注入」のまま変わらない
     → 「今すぐ注入」ボタンを押す。ウイルス対策ソフトのブロックを確認。
  「swhook: フック失敗」
     → サーバーを再起動してもう一度。それでも出る場合は下記へ。
  それでも不具合があるときは、置いたフォルダ内の「captures」フォルダに
  できる .log ファイルを送ってください（原因調査に使います）。
  「ログ・録画」タブの「録画開始」で .swcap も一緒に送ってもらえると
  より確実に調べられます。

------------------------------------------------------------------------
 他のソフトから使いたい人向け（上級者）
------------------------------------------------------------------------
  swctl.exe で全操作がコマンドラインからできます（引数なしで一覧）。
    swctl inject --wait     サーバー起動を待って組み込み（管理者権限）
    swctl status / peers / vehicles / watch
    swctl relay on|off
  同じ内容を 127.0.0.1:28215 に JSON 1行で送ることもできます（仕様は
  ipc-protocol.md を参照）。
